# Gestor de usuarios

Login y mantenimiento de usuarios. La documentación completa está en [DOCUMENTACION.md](DOCUMENTACION.md).

| Parte | Cómo abrirla |
|---|---|
| Base | SSMS, instancia `localhost\SQLEXPRESS`, ejecutar `database/UsuariosDb.sql` |
| API | `backend/Usuarios.sln` en Visual Studio, F5. Queda en http://localhost:5087 |
| Pantalla | En `frontend`, `npm install` y `npm start`. Queda en http://localhost:4317 |

Cuenta inicial del script: `admin` / `Admin123!`
